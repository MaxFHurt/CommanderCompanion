# Commander Companion visual handoff

[Integration instructions](../Commander-Companion-Claude-Integration-Handoff.md) and [the archive download index](../visual-rebuild-handoff.md) are in the roadmap.

`layout-reference/` contains the iPhone and iPad placement maps and palette configuration. `archive-manifest.json` lists the planned repository path, size and SHA-256 for each of the 13 archive parts. The binary archives are currently available through the download index.
