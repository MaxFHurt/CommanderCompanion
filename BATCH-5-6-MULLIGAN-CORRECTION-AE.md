# Commander Companion V0.8 AE — Opening Hand Mulligan Correction

Batch 5-6 remains open. This corrective iteration changes the opening-hand RANDOM HAND action into MULLIGAN and applies the selected mulligan rule.

- Commander: first mulligan is free; each later mulligan increases the number of cards placed on the bottom by one.
- London: each mulligan increases the number of cards placed on the bottom by one.
- Free mulligans: no cards are placed on the bottom regardless of mulligan count.
- Every mulligan shuffles the current hand back into the tracked library and draws seven new cards.
- Cards are put on the bottom only when the player keeps/confirms the hand, matching London-style mulligan flow.
- The player chooses exactly which required cards go to the bottom.
- Single-device and private multi-device opening-hand flows use the same rule calculation.
- No combat, mana, trigger, priority, startup/cache, or unrelated gameplay changes were made.
